# OMDL: Clinic Appointment Management System

OMDL (Olympus Medical and Diagnostic Laboratory System) is a web-based healthcare management system designed to streamline clinic operations, improve patient satisfaction, and enhance service efficiency through digital solutions.

---

## Overview

Traditional clinic processes rely on manual scheduling and record-keeping, which can lead to delays, errors, and inefficiencies.  

OMDL solves these problems by providing a centralized platform that allows real-time appointment booking, digital patient record management, and automated notifications.

---

## Objectives

- Improve clinic service efficiency  
- Enhance patient experience  
- Reduce manual workload and errors  
- Provide real-time access to appointments and records  
- Support data-driven decision making  

---

## Features

### Patient
- Register and log in  
- Book appointments in real time  
- View appointment history  
- Access medical records  
- Receive notifications  

### Admin
- Manage appointments (approve, decline, reschedule)  
- Manage patient records  
- Assign doctors and schedules  
- Manage services and system settings  
- View dashboard and analytics  

---

## System Capabilities

- Real-time appointment scheduling  
- Centralized patient records  
- Automated email notifications  
- Dashboard and analytics  
- Secure data handling

## Installation

Clone the repository
```bash
git clone https://github.com/charlenebaltazar/OMDL-----Clinic-Appointment-Management-System.git
```
Go to project folder
```bash
cd OMDL-----Clinic-Appointment-Management-System
```
Install dependencies
```bash
npm install
```
Run the Project
```bash
npm run dev
```
Open in your browser
```bash
http://localhost:3000
```

## Scope

The system focuses on:

- Appointment booking and management  
- Patient data storage and retrieval  
- Monitoring of clinic services  

It is designed to be:

- User-friendly  
- Scalable  
- Accessible across multiple devices  

---

## Limitations

- No real-time chat or messaging feature  
- No built-in chatbot support  
- Limited customization of services  
- No AI-based health analysis  
- Relies on external APIs (e.g., Google Calendar, email services)
